# Hallowpoint
A 2D pixel top-down post-apocalyptic mystery game developed as a Software Engineering project by Computer Science students at the University of the East.

About the Project
Hallowpoint is an atmospheric narrative-driven adventure set in the remnants of a ruined world. Players take on the role of an investigator navigating desolate terrain, piecing together fragments of a forgotten past, and uncovering dark secrets hidden beneath the ash. Built using the Godot Engine, this project follows structured software engineering principles, agile development workflows, and clean code architecture.

Features
Top-Down 2D Exploration: Navigate meticulously crafted pixel-art environments.

Mystery & Investigation Mechanics: Gather clues, interrogate survivors, and solve narrative-driven puzzles.

Post-Apocalyptic Setting: Experience a moody, atmospheric world brought to life through detailed pixel art and immersive sound design.

Modular Architecture: Built with clean GDScript practices tailored for maintainability.

Tech Stack
Game Engine: Godot Engine (GDScript)

Art & Design: Aseprite / Custom Pixel Art Assets

Version Control: Git & GitHub

Project Structure:

Hallowpoint/
├── assets/          # Sprites, tilesets, audio, and UI elements
├── scenes/          # Godot scene files (.tscn) for levels, UI, and entities
├── scripts/         # GDScript logic files governing game systems and mechanics
└── project.godot    # Main Godot project configuration file
